## Теоретическая часть

### 1.1. Введение в задачу поиска кратчайшего пути

Каждому ребру графа присваивается вес (некоторая мера), например, расстояние между вершинами[cite: 5]. Матрица смежности преобразуется в матрицу весов, где элемент $a_{ij}$ равен весу ребра (дуги), соединяющего $i$-ю и $j$-ю вершины[cite: 5].

  

Главная задача заключается в определении кратчайшего расстояния от заданной вершины до всех остальных[cite: 5].

  

### 1.2. Алгоритм Дейкстры

Алгоритм позволяет найти кратчайший путь между некоторой вершиной и остальными при условии, что в графе нет дуг (рёбер) с отрицательным весом[cite: 5].

  

- **Основная идея:** Поиск кратчайшего пути начинается от исходной вершины к одной из смежных[cite: 6]. Затем процесс продолжается от вершин с уже найденными кратчайшими путями до следующих смежных вершин, пока не будут найдены пути ко всем вершинам[cite: 6].
    
      
    
- Для этого составляется вспомогательная таблица[cite: 6].
    
      
    
- На первом шаге вычисляются пути от исходной вершины (например, $x_1$) до смежных с ней[cite: 6]. Путь от вершины до самой себя принимается равным $0$ и помечается символом `*` (как далее не вычисляемый)[cite: 6]. Для несмежных вершин путь принимается равным бесконечности[cite: 6].
    
      
    
- На каждом шаге выбирается вершина с наименьшим вычисленным кратчайшим путем (помеченная `*`), и процедура повторяется для её соседей[cite: 7, 8].
    
      
    
- Для восстановления полного пути для конкретной вершины из последней строки таблицы последовательно находятся предшествующие вершины вплоть до начальной[cite: 8].
    
      
    

### 1.3. Алгоритм Флойда-Уоршолла

Для графов, содержащих рёбра с отрицательными весами, используется алгоритм Флойда-Уоршолла[cite: 8].

💡 **Совет по реализации:**

  

- Для программной реализации алгоритма Дейкстры удобно использовать структуру данных **приоритетная очередь** (`priority_queue` в C++ или модуль `heapq` в Python), что позволяет эффективно выбирать вершину с минимальным текущим расстоянием.
    
      
    
- При реализации алгоритма Флойда-Уоршолла используйте три вложенных цикла по промежуточной вершине $k$, а также начальной $i$ и конечной $j$ вершинам, выполняя обновление матрицы по формуле: $dist[i][j] = \min(dist[i][j], dist[i][k] + dist[k][j])$.
