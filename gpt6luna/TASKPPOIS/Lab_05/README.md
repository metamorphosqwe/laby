# Лаба 5. Наследование

Вариантов нет. Значения для примера заданы в программе.

В PowerShell из папки `TASKPPOIS\Lab_05` выполни:

```powershell
g++ -std=c++17 .\main.cpp -o .\lab05.exe
.\lab05.exe
```

Один класс наследует данные и функции от двух других классов. Программа
показывает вызовы функций через объекты и указатели, включая виртуальную функцию.
