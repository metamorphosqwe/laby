# Лаба 2. Перегрузка функций

Номерных вариантов нет. Значения для примера уже заданы в программе.

В PowerShell из папки `TASKPPOIS\Lab_02` выполни:

```powershell
g++ -std=c++17 .\main.cpp -o .\lab02.exe
.\lab02.exe
```

В программе несколько функций с именем `set`. Они отличаются входными данными.
Так показано, как C++ выбирает подходящую функцию. Также объясняется, почему
нельзя создать две функции, которые отличаются только типом результата.
