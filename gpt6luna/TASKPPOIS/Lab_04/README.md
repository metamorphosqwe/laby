# Лаба 4. Дружественные функции

Вариантов нет. Примерные данные заданы прямо в программе.

В PowerShell из папки `TASKPPOIS\Lab_04` выполни:

```powershell
g++ -std=c++17 .\main.cpp -o .\lab04.exe
.\lab04.exe
```

Программа показывает три примера доступа к закрытым данным класса:
дружественная функция, функция-друг для двух классов и дружественный класс.
