# Лаба 1. Класс «Студент»

Вариантов в этой работе нет. Данные для примера уже записаны в программе.

Открой PowerShell в папке `TASKPPOIS\Lab_01` и выполни:

```powershell
g++ -std=c++17 .\main.cpp -o .\lab01.exe
.\lab01.exe
```

Программа создаёт студентов, показывает их данные и демонстрирует копирование,
присваивание и операции `+` и `++`. Массив оценок имеет пять ячеек.
