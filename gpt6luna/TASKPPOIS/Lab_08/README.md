# Лаба 8. Работа с файлами

Вариантов нет. Программа сама создаёт файл `students.txt` с примером данных,
затем читает его. Файл остаётся в папке лабы, его можно открыть и посмотреть.

В PowerShell из папки `TASKPPOIS\Lab_08` выполни:

```powershell
g++ -std=c++17 .\main.cpp -o .\lab08.exe
.\lab08.exe
```

В выводе показано чтение и запись файла, а также сохранение и загрузка списка
студентов. Используются потоки C++ для чтения и записи.
