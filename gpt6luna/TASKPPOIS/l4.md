## 💡 Совет по реализации

При объявлении дружественной функции не забудь указать ключевое слово `friend` внутри класса, например:

```cpp
class MyClass {
private:
    int secretValue;

public:
    MyClass(int value) : secretValue(value) {}

    friend void showSecret(const MyClass& obj);
};

void showSecret(const MyClass& obj) {
    // Дружественная функция имеет доступ к private-полю
    std::cout << "Secret value: " << obj.secretValue << std::endl;
}
```

Если нужно продемонстрировать дружественный класс, удобно вынести его методы так, чтобы они могли читать и изменять закрытые поля основного класса:

```cpp
class Accessor; // предварительное объявление

class Data {
private:
    int value;

public:
    Data(int v) : value(v) {}

    friend class Accessor;
};

class Accessor {
public:
    void printValue(const Data& d) {
        std::cout << d.value << std::endl; // доступ к закрытому полю
    }
};
```

На UML-диаграмме связь «дружественный класс» можно отобразить как зависимость или стереотип `«friend»`, а сам класс `Accessor` связать с классом `Data`. Это сделает структуру понятной для преподавателя и упростит защиту работы.
