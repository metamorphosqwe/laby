## 📌 Задание

Необходимо реализовать иерархию из **трёх классов**.

### 1. Два базовых класса

Производный класс должен наследовать **оба базовых класса**.

То есть требуется реализовать **множественное наследование**.

---

### 2. Метод с одинаковым именем в базовых классах

В обоих базовых классах реализовать метод:

- с **одинаковым именем**;
- но с **разным поведением**.

В производном классе создать метод, который вызывает оба варианта этого метода, используя **разрешение области видимости**.

Примерный смысл такого вызова:

```cpp
Base1::someMethod();
Base2::someMethod();
```

---

### 3. Конструкторы и переменные-члены

Во всех классах определить:

- конструкторы;
- необходимые переменные-члены.

---

### 4. Пример с виртуальными функциями

Отдельно реализовать пример с виртуальными функциями:

1. В одном из базовых классов объявить метод как `virtual`.
2. В производном классе переопределить этот метод с использованием ключевого слова `override`.

---

## ⚙️ Демонстрация в функции `main()`

В функции `main()` необходимо продемонстрировать:

1. Вызов всех `public`-членов базовых классов через объекты базовых классов.

2. Вызов всех `public`-членов базовых и производного классов через объект производного класса.

3. Вызов тех же членов через указатели на объекты с использованием оператора `->`.

4. Для виртуального метода показать различие вызова:
   - при обращении через указатель базового класса на объект производного класса;
   - при прямом вызове через объект.

## 💡 Совет по реализации

При множественном наследовании, если в двух базовых классах есть метод с одинаковым именем, компилятор не сможет сам понять, какой именно метод вызывать. Поэтому в производном классе всегда явно указывай область видимости:

```cpp
class Base1 {
public:
    void action() {
        // поведение первого базового класса
    }
};

class Base2 {
public:
    void action() {
        // поведение второго базового класса
    }
};

class Derived : public Base1, public Base2 {
public:
    void action() {
        Base1::action();
        Base2::action();
    }
};
```

Для демонстрации виртуальных функций удобно использовать указатель на базовый класс:

```cpp
Base1* ptr = new Derived();
ptr->virtualMethod(); // вызовется переопределённый метод из Derived
```

Если объект создаётся динамически через `new`, не забудь добавить в базовый класс **виртуальный деструктор**, чтобы удаление через указатель на базовый класс работало корректно.
