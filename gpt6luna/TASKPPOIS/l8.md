## 📌 Задание

Реализовать программы, демонстрирующие:

1. Чтение данных из потока с использованием метода `get()` и функции `getline()`.

2. Вывод данных в поток с использованием метода `put()`.

3. Организацию файлового ввода-вывода с использованием классов:
   - `ifstream`;
   - `ofstream`;
   - `fstream`.

4. Применение манипуляторов потока:
   - `setw`;
   - `setprecision`;
   - `fixed`;
   - `endl`;
   - и других.

5. Сохранение массива объектов пользовательского класса в файл и загрузку массива объектов из файла.

> ℹ️ Класс может быть взят из предыдущих лабораторных работ или разработан заново.

## 💡 Совет по реализации

При работе с файлами всегда проверяй, что файл успешно открыт:

```cpp
std::ifstream inFile("data.txt");

if (!inFile) {
    std::cout << "Ошибка открытия файла" << std::endl;
}
```

Для сохранения объектов в текстовом файле удобно перегружать операторы `<<` и `>>`:

```cpp
std::ostream& operator<<(std::ostream& out, const MyClass& obj);
std::istream& operator>>(std::istream& in, MyClass& obj);
```

Тогда сохранение и загрузка массива будут выглядеть аккуратно:

```cpp
for (int i = 0; i < n; ++i) {
    out << objects[i] << std::endl;
}
```

Если будешь использовать `std::getline`, помни, что после ввода числа через `std::cin` в потоке может остаться символ перевода строки. Его можно убрать через:

```cpp
std::cin.ignore();
```

Это часто помогает избежать пустого результата при первом вызове `getline`.
