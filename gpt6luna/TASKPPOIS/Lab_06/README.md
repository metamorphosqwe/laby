# Лаба 6. Пространства имён и ошибки

Вариантов нет. Программа сама запускает несколько примеров.

В PowerShell из папки `TASKPPOIS\Lab_06` выполни:

```powershell
g++ -std=c++17 .\main.cpp -o .\lab06.exe
.\lab06.exe
```

В двух пространствах имён есть классы с одинаковым названием. Программа
показывает обычную работу и обработку ошибок, например деление на ноль.
