# Лаба 3. Ссылки и массив

Использован вариант 4: массив чисел `int`. Все данные примера находятся
внутри программы, отдельные файлы не нужны.

В PowerShell из папки `TASKPPOIS\Lab_03` выполни:

```powershell
g++ -std=c++17 .\main.cpp -o .\lab03.exe
.\lab03.exe
```

Программа показывает копирование массива, работу ссылок и указателей, а также
что происходит при обращении к элементу за границей массива.
