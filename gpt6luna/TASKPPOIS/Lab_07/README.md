# Лаба 7. Шаблоны

Вариантов нет. Все примеры находятся в `main()`.

В PowerShell из папки `TASKPPOIS\Lab_07` выполни:

```powershell
g++ -std=c++17 .\main.cpp -o .\lab07.exe
.\lab07.exe
```

Шаблонная функция складывает значения. Шаблонный класс хранит значение.
Примеры показаны для целых чисел, дробных чисел и строк.
