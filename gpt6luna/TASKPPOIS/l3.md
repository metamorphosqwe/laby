## 📌 Задание

На основе предметной области, выбранной в **лабораторной работе № 1**, необходимо реализовать класс, содержащий следующие элементы:

### 1. Динамический массив

- Для студентов с **чётным** номером в списке группы — массив типа `int[]`.
- Для студентов с **нечётным** номером — массив типа `char[]`.
- Массив должен:
  - выделяться динамически в конструкторах с помощью `new[]`;
  - освобождаться в деструкторе с помощью `delete[]`.
- Необходимо корректно реализовать **конструктор копирования** и **оператор присваивания `=`**, чтобы избежать:
  - поверхностного копирования;
  - утечек памяти.
- Размер массива задаётся либо как константа, либо передаётся в конструктор (по варианту).

### 2. Ссылочная переменная

В классе должна присутствовать **ссылочная переменная** (например, ссылка на строку, число или другой объект). Необходимо продемонстрировать:

- Изменение значения ссылки при изменении объекта, на который она ссылается.
- Передачу и возврат **по ссылке** в методах класса или внешних функциях.
- Отличие передачи/возврата **по ссылке** от передачи/возврата **по значению**.

### 3. Способы возврата массива из функции

Реализовать и продемонстрировать **все основные способы** возврата массива из функций (методов класса):

| № | Способ возврата | Описание |
|---|-----------------|----------|
| 1 | Возврат **указателя** на массив | `int* getArray()` |
| 2 | Возврат **ссылки** на массив | `int (&getArrayRef())[N]` |
| 3 | Возврат **ссылки на отдельный элемент** массива | `int& getElement(int index)` |

> ℹ️ Каждый способ должен быть продемонстрирован в `main()`:
> - вызваны соответствующие методы;
> - показаны полученные значения;
> - показана возможность их изменения (если это допустимо).

### 4. UML-диаграмма класса

Построить UML-диаграмму разработанного класса. На диаграмме должны быть отражены:

- **Имя класса**.
- **Поля (атрибуты)** с указанием типа и модификатора доступа:
  - `-` для `private`
  - `+` для `public`
- **Методы (операции)** с указанием:
  - модификатора доступа;
  - типов параметров;
  - возвращаемого значения.
- **Конструкторы** (по умолчанию, с параметрами, копирования) и **деструктор**.
- **Связи** (если есть) с другими классами.

> ⚠️ **Внимание:** Начиная с этой лабораторной работы, **UML-диаграмму необходимо выполнять для каждой последующей работы**.

## 💡 Совет по реализации

Самая частая проблема в этой работе — **утечки памяти и двойное освобождение** при работе с динамическим массивом. Чтобы этого избежать, придержи правила **«Rule of Three»**: если ты определил одно из трёх (деструктор, конструктор копирования, оператор `=`), то нужно определить **все три**.

Пример безопасного оператора присваивания через **copy-and-swap** идиому:

```cpp
MyClass& operator=(const MyClass& other) {
    if (this != &other) {               // защита от самоприсваивания
        delete[] arr;                   // освобождаем старый массив
        size = other.size;
        arr = new int[size];            // выделяем новый
        for (int i = 0; i < size; ++i)
            arr[i] = other.arr[i];      // копируем элементы
    }
    return *this;
}
```

Для **ссылочного поля** помни: ссылка в C++ **должна быть инициализирована в списке инициализации конструктора** и её нельзя «перепривязать» позже. Если нужно менять «привязанный» объект в течение жизни класса — лучше использовать указатель вместо ссылки, но в рамках этой работы требуется именно ссылка, поэтому продумай её инициализацию заранее (например, через параметр конструктора `int& externalRef`).

Для UML-диаграммы удобно использовать бесплатные инструменты: **PlantUML**, **draw.io (diagrams.net)** или **StarUML** — они позволяют быстро построить диаграмму и экспортировать её в PNG для отчёта.
