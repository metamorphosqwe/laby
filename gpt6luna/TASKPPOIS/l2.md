# Лабораторная работа № 2

## Перегрузка функций. Разработка и реализация пользовательских классов

> **Вариант:** в исходном тексте не указан  
> *Работа выполняется на основе класса, реализованного в лабораторной работе № 1.*

## 🎯 Цели работы

1. Изучение механизмов перегрузки функций.
2. Практика программирования пользовательских классов.

## 📌 Задание

На основе класса, реализованного в предыдущей лабораторной работе, необходимо продемонстрировать следующие виды перегрузки функций:

1. Перегрузка с разным количеством параметров.
2. Перегрузка с разными типами параметров.
3. Сочетание различий по числу и типу параметров.
4. Перегрузка с использованием `const`-квалификаторов параметров.
5. Демонстрация невозможности перегрузки только по возвращаемому типу.

---

## 🏗️ Требования к реализации

- В классе, разработанном в лабораторной работе № 1, добавить перегруженные методы, иллюстрирующие указанные виды перегрузки.  
  Например, это могут быть:
  - конструкторы;
  - методы `TO_SET`;
  - методы `TO_GET`;
  - дополнительные методы класса.

- При использовании `const`-квалификаторов объяснить в комментариях:
  - зачем это нужно;
  - как компилятор различает такие функции.

- В функции `main()` продемонстрировать вызов всех перегруженных функций, явно комментируя, какой именно вариант функции вызывается в каждом случае.

- Для демонстрации невозможности перегрузки только по возвращаемому типу можно привести пример кода в закомментированном виде с пояснением, что такой код не скомпилируется.

---

## ⚠️ Примечания

- Перегрузка операторов также является перегрузкой функций, однако в данной работе требуется перегружать **не операторы**.
- При перегрузке методов класса важно помнить:
  - `const`-метод не может изменять поля класса;
  - не-`const` метод может изменять поля класса;
  - это позволяет использовать `const`-объекты.

---

💡 **Совет по реализации:**  
Для этой работы удобно добавить несколько вариантов `TO_SET`, например:

```cpp
void TO_SET_value(int newValue);
void TO_SET_value(double newValue);
void TO_SET_value(int newValue, int index);
```

А для демонстрации `const`-методов можно сделать пару:

```cpp
int TO_GET_value() const;
void TO_GET_value();
```

Но будь внимателен: перегрузка только по возвращаемому типу в C++ запрещена, поэтому такой код лучше оставить в комментариях и рядом написать пояснение, почему компилятор не сможет выбрать нужную функцию.
