# Лаба 3. Кратчайшие пути

## Как запустить

```powershell
gcc -std=c11 .\main.c -o .\lab03.exe
.\lab03.exe .\test_01.txt
```

Есть 20 примеров. Чтобы запустить другой, укажи его имя вместо `test_01.txt`.

В файле указаны число вершин и рёбер, начальная вершина, а затем сами рёбра с
их длиной. Программа двумя способами находит кратчайшие пути от начальной
вершины и печатает расстояние и маршрут.

## Проверки

Проверены разные начальные вершины, нулевые веса и вершины, до которых нельзя
добраться. Оба способа должны показать одинаковые расстояния.
