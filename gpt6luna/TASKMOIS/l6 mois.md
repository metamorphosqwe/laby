### 1. Обход дерева и его способы

**Обход дерева** — это упорядоченная последовательность вершин дерева, в которой каждая вершина встречается только один раз[cite: 16]. При обходе все вершины дерева должны посещаться в определённом порядке[cite: 16].

  

Рассмотрим три наиболее часто используемых способа обхода дерева[cite: 16]:

  

1. **Прямой обход (Pre-order):** Корень $\to$ Левое поддерево $\to$ Правое поддерево[cite: 16].
    
      
    
2. **Симметричный обход (In-order):** Левое поддерево $\to$ Корень $\to$ Правое поддерево[cite: 16].
    
      
    
3. **Обратный обход (Post-order):** Левое поддерево $\to$ Правое поддерево $\to$ Корень[cite: 16].
    
      
    

#### Пример обходов (по рисунку из описания)

- **Прямой обход:** `A -> B -> D -> E -> C -> F`[cite: 16]
    
      
    
- **Симметричный обход:** `D -> B -> E -> A -> C -> F`[cite: 16]
    
      
    
- **Обратный обход:** `D -> E -> B -> F -> C -> A`[cite: 16]

💡 **Совет по реализации:**

  

- **Определение структуры:** Постройте деревья в памяти в виде структуры узла с указателями на левого и правого потока (`left`, `right`).
    
      
    
- **Проверка на изоморфизм:** Простейший рекурсивный алгоритм изоморфизма бинарных деревьев `isIsomorphic(T1, T2)` проверяет:
    
      
    1. Если оба узла `null` — возвращаем `true`.
        
          
        
    2. Если только один узел `null` или их значения не совпадают — `false`.
        
          
        
    3. Возвращаем `(isIsomorphic(T1.left, T2.left) && isIsomorphic(T1.right, T2.right)) || (isIsomorphic(T1.left, T2.right) && isIsomorphic(T1.right, T2.left))`.
        
          
        
- **Сбалансированность:** Дерево является сбалансированным по высоте (AVL-сбалансированным), если для каждого узла разница высот его левого и правого поддеревьев не превышает 1 ($\vert{}\text{height}(L) - \text{height}(R)\vert{} \le 1$).
