# Лаба 4. Минимальное остовное дерево

## Как запустить

```powershell
gcc -std=c11 .\main.c -o .\lab04.exe
.\lab04.exe .\test_01.txt
```

В папке 20 примеров. Замени имя файла, чтобы выбрать другой.

В файле записаны вершины, рёбра и вес каждого ребра. Программа находит
минимальное дерево, которое соединяет все вершины. Для сравнения используются
два способа поиска. Если граф не удаётся соединить, программа об этом сообщает.

## Проверки

Проверены связные и несвязные графы, нулевые и одинаковые веса. Оба способа
дали одинаковый общий вес дерева.
