# Лаба 2. Циклы в графах

## Как запустить

Открой PowerShell в этой папке и выполни:

```powershell
gcc -std=c11 .\main.c -o .\lab02.exe
.\lab02.exe .\test_01.txt
```

Чтобы выбрать другой пример, замени `test_01.txt` на нужный файл от `test_01.txt`
до `test_20.txt`.

В каждом файле записаны два графа. Программа ищет в первом графе эйлеров цикл
(проходит каждое ребро один раз и возвращается назад), а во втором — гамильтонов
цикл (посещает каждую вершину один раз).

## Проверки

Программа собрана и запущена на всех 20 файлах. Проверялись графы с циклами,
без циклов, с отдельными вершинами и без рёбер.
