# Лаба 8. Заполнение доски

## Как запустить

```powershell
gcc -std=c11 .\main.c -o .\lab08.exe
.\lab08.exe .\test_01.txt
```

В файле указана длина стороны доски. Программа нумерует клетки по разрешённым
условием ходам и старается заполнить как можно больше клеток. Пустые клетки
показываются точкой. В папке есть 20 примеров.

## Проверки

Проверены доски разного размера от 1 до 8. Последний файл содержит неправильный
размер и нужен для проверки сообщения об ошибке.
