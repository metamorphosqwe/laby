# Лаба 5. Связность графов

## Как запустить

```powershell
gcc -std=c11 .\main.c -o .\lab05.exe
.\lab05.exe .\test_01.txt
```

Есть 20 примеров. В каждом записаны два графа: первый со стрелками, второй
без стрелок. Программа показывает группы вершин, между которыми можно пройти
туда и обратно, а для второго графа находит важные вершины и рёбра. Важная
вершина или ребро разделяет граф, если его убрать.

## Проверки

Проверены графы с циклами, отдельными вершинами и несколькими частями.
