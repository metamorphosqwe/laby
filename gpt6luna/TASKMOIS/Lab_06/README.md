# Лаба 6. Деревья

## Как запустить

```powershell
gcc -std=c11 .\main.c -o .\lab06.exe
.\lab06.exe .\test_01.txt
```

Выбери один из 20 файлов. В каждом записаны два дерева. Корень дерева — вершина
1 (в задании это вершина `a`). Остальные вершины обозначены числами 2, 3 и далее.

Программа показывает порядок обхода дерева, высоту и проверяет, похожи ли
деревья по форме. Также проверяет, поможет ли удаление одного листа сделать их
одинаковыми.

## Проверки

Проверены одинаковые и разные деревья, цепочки и деревья с несколькими ветками.
