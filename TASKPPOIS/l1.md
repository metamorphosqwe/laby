### 🏗️ Требования к классу

1. **Свойства-атрибуты:**
   - Три свойства-атрибута, одно из которых — **статический массив целых чисел фиксированного размера** (например, `int values[5]`).
   - *Динамические массивы, указатели и контейнеры STL не использовать.*

2. **Конструкторы (три вида):**
   - **По умолчанию:** инициализирует все поля значениями по умолчанию, массив — нулями.
   - **С параметрами:** принимает значения для всех полей, включая массив.
   - **Копирования:** создаёт копию объекта, включая копирование всех элементов массива.

3. **Методы (достаточные для вывода, установки и получения значений свойств):**
   - `TO_SHOW()` — вывод всей информации об объекте.
   - `TO_GET_<ИмяСвойства>()` — получение значения свойства.
   - `TO_SET_<ИмяСвойства>(новое значение)` — установка значения свойства.
   - *Все данные класса должны быть закрытыми (`private`), методы — открытыми (`public`).*

4. **Перегруженные операторы (три вида):**
   - **Оператор присваивания `=`:** присваивает все поля, включая массив.
   - **Бинарный оператор** (например, `+`, `-`, `==`) — смысл выбрать самостоятельно и описать в комментарии.
   - **Унарный оператор** (например, `++`, `--`, `!`) — смысл выбрать самостоятельно и описать в комментарии.

### ⚙️ Требования к функции `main()`

1. **Создать три объекта класса:**
   - **Объект 1** — с использованием конструктора по умолчанию.
   - **Объект 2** — с использованием конструктора с параметрами.
   - **Объект 3** — с использованием конструктора копирования (на основе объекта 2).

2. **Продемонстрировать работу всех методов:**
   - Вызвать `TO_SET` и `TO_GET` для разных свойств.
   - Вызвать `TO_SHOW` для каждого объекта.

3. **Продемонстрировать работу перегруженных операторов:**
   - Выполнить присваивание (например, `объект1 = объект2`).
   - Выполнить бинарную операцию (например, `объект1 + объект2`) и вывести результат.
   - Выполнить унарную операцию (например, `++объект1`) и вывести результат.

> ⚠️ **Примечания:**
> 1. Для массива фиксированного размера рекомендуется объявить константу размера (например, `const int SIZE = 5;`).
> 2. При реализации оператора `=` не забыть скопировать все элементы массива.
> 3. В отчёте обязательно указать выбранную предметную область и пояснить смысл перегруженных операторов.

💡 **Совет по реализации:**
Поскольку использовать STL и динамические массивы запрещено, для поэлементного копирования статического массива в конструкторе копирования и операторе `=` используй обычный цикл `for` (или `memcpy` из `<cstring>`, если хочешь написать чуть более "профессионально", но цикл надежнее для понимания). При выборе бинарного оператора (например, `+` для сложения двух "Студентов") подумай о логике: можно суммировать их массивы оценок, общий стаж или средние баллы. Возвращай результат бинарного оператора как **новый объект по значению**, чтобы не изменять исходные операнды!
