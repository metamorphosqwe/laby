Отчёт по лабораторной работе должен содержать следующие разделы:

- Текст программы.
- Скриншоты, демонстрирующие работу программы:

  - обработка исключений из разных пространств имён.
- Выводы по проделанной работе.

---

## 📌 Задание

1. Создать **два пространства имён**.  
   В каждом пространстве определить класс с **одинаковым названием**.

2. В каждом классе реализовать метод, который может вызвать исключение.

3. Организовать обработку исключений с использованием блоков `try` и `catch`.

4. Реализовать как минимум **два типа исключений**:
   - стандартное исключение;
   - пользовательское исключение собственного типа — класс, определённый в одном из пространств имён.

5. Продемонстрировать, что исключения, сгенерированные в разных пространствах имён, можно обрабатывать раздельно, то есть использовать разные блоки `catch`.

6. При перехвате исключения выводить в консоль сообщение о:
   - типе ошибки;
   - причине ошибки.

   Сообщение можно выводить через метод `what()` или через собственный метод класса исключения.

## 💡 Совет по реализации

Чтобы избежать конфликтов имён, при создании объектов или обработке исключений указывай полное имя через пространство имён, например:

```cpp
NamespaceA::MyClass objA;
NamespaceB::MyClass objB;
```

Для пользовательского исключения удобно наследоваться от `std::exception` и переопределять метод `what()`:

```cpp
class CustomException : public std::exception {
public:
    const char* what() const noexcept override {
        return "Custom exception from NamespaceA";
    }
};
```

Исключения лучше перехватывать по константной ссылке:

```cpp
catch (const NamespaceA::CustomException& e) {
    std::cout << e.what() << std::endl;
}
```

Это позволяет сохранять объект исключения и избежать лишнего копирования.
