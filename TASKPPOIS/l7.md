## 💡 Совет по реализации

Реализации шаблонов функций и классов лучше размещать в заголовочном файле `.hpp` или `.h`, потому что компилятору нужно видеть определение шаблона в момент инстанцирования.

Пример простой шаблонной функции:

```cpp
template <typename T>
T process(T value) {
    return value;
}
```

Пример шаблонного класса:

```cpp
template <typename T>
class Container {
private:
    T data;

public:
    Container(T value) : data(value) {}

    T getData() const {
        return data;
    }
};
```

В `main()` удобно продемонстрировать работу с несколькими типами, например:

```cpp
Container<int> intContainer(10);
Container<double> doubleContainer(3.14);
Container<std::string> stringContainer("Hello");
```

Это наглядно покажет, что один и тот же шаблон может работать с разными типами данных.
